# 相册导出与导入

回忆相册右上角的下载按钮打开导出与导入面板，导出整个当前两人相册，不受搜索、筛选或分页影响。

| 格式         | 包含内容                                                                                              | 使用方式                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 普通照片 ZIP | 按相册日期命名的 JPEG 照片，来自压缩预览                                                              | 直接解压，可在普通图片软件打开，不含视频                        |
| 完整相册 ZIP | manifest.json、照片与视频预览、缩略图、实际保留的原文件；每条回忆的日期、描述、原上传时间、作者显示名 | 可导入 Love，原作者显示名保存在导出清单中，导入后由导入用户发布 |

Web 使用浏览器下载，Android 通过原生文件传输下载到应用缓存，再打开系统分享，可选择文件管理器保存。导出文件包含两人私人媒体，按自己的需要保存。导出链接 20 分钟内可开始下载，下载前验证登录会话及当前配对；退出或解除配对后新请求失效，路径凭据在访问日志中隐藏。

完整导入新增回忆，不覆盖现有相册，保留日期、描述、原上传时间和压缩媒体。元数据中的媒体 ID 重建为当前空间的新 ID，不恢复原账号权限，不导入聊天或服务器配置。同一个 ZIP 内容再次导入不会重复增加记录；重新导出生成的新 ZIP 视为新导入包。

导入遵循当前两人空间的媒体策略：仅保存压缩版本时忽略导出包原文件，不增加原文件占用；开启保留原文件时保存包内已有原文件，没有原文件的媒体仍然只有压缩版。缩略图及预览实际字节计入配对额度。剩余空间不足、文件缺失、哈希错误、非法路径、ZIP 结构错误或媒体无法识别时不保存任何回忆，清理临时文件。

格式标记为 `format: love-album`、`version: 1`。media 项记录 UUID、kind、width、height、duration、createdAt、original（允许 null）、preview 和 thumbnail；文件对象记录相对 path、bytes 和 sha256。moments 项记录 mediaId、title、date、createdAt、author。导出仅包含当前相册引用的媒体；不含用户 token、密码、SMTP 或 AI Key。

上传不设置单文件大小、图片像素、视频分辨率或时长上限；压缩预览仍生成 1600 像素内 WebP 图片、1280×720 内 H.264/AAC 视频及缩略图。管理员分配的总空间额度仍然有效；硬盘、设备内存及反向代理配置决定实际可处理规模。内置 Caddy 不设请求体大小上限，外部代理需自行取消大小限制并给予足够处理时间。
