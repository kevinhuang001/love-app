# 配置管理边界

部署与启动身份放 `.env`，运行规则放管理员后台，两人的偏好放“我们”。每项只保留一个权威来源，管理脚本不直接修改数据库里的业务设置。

| 位置     | 配置                                                                                                | 生效方式                                                                         |
| -------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `.env`   | `ADMIN_USERNAME`、`ADMIN_PASSWORD`                                                                  | 每次启动同步管理员凭据，修改后应用部署配置；变化时撤销管理会话，值未变则保留会话 |
| `.env`   | `LOVE_DATABASE`、`DATABASE_PROVIDER`、`DATABASE_URL`、`POSTGRES_DB/USER/PASSWORD`                   | 重新创建容器；切换数据库不会搬迁数据                                             |
| `.env`   | `LOVE_BIND_IP/PORT`、`LOVE_HTTPS`、`LOVE_DOMAIN`、`LOVE_TLS_PROVIDER/PORT/BIND_IP`、`CERTBOT_EMAIL` | 应用部署配置，控制宿主机监听、代理和证书服务                                     |
| `.env`   | `ALLOWED_ORIGINS`、`TRUST_PROXY`、`AI_ALLOWED_HOSTS`                                                | 重启生效；高级部署选项可修改                                                     |
| `.env`   | `MEDIA_SIGNING_SECRET`                                                                              | 稳定密钥，随备份保存；更换后重填 SMTP 密码与 AI Key                              |
| `.env`   | `COMPOSE_PROJECT_NAME`、`LOVE_IMAGE`                                                                | 项目名决定数据卷；镜像只使用官方 GHCR，更新自动记录 digest                       |
| 管理后台 | 注册开放/关闭/白名单、邮箱域名、是否要求邀请码、白名单列表                                          | 保存后立即生效                                                                   |
| 管理后台 | 邀请码批量生成、次数、期限、停用                                                                    | 立即生效，完整邀请码只在生成后显示一次                                           |
| 管理后台 | SMTP 主机、端口、加密、账号、密码、发件邮箱和名称、测试邮件                                         | 数据库加密保存，不写 `.env`                                                      |
| 管理后台 | 新配对默认额度、各配对独立额度、日志保留期                                                          | 保存后立即生效；更改默认额度不覆盖已有配对额度                                   |
| 管理后台 | 用户创建、停用、密码重置、撤销会话                                                                  | 立即生效                                                                         |
| 两人设置 | AI 地址/模型/Key/名称/头像、是否保留媒体原文件、在一起时间                                          | 配对共享，双方可修改                                                             |
| 个人设置 | 名称、头像、主题、客户端服务器地址、本地通知                                                        | 按用户或设备保存                                                                 |

`./love` 负责 `.env`、启停、检查更新、备份恢复、日志和卸载。新安装默认关闭自助注册、默认配对额度 1024 MiB，管理员登录 `/#admin` 配置运行规则。没有 `INITIAL_*` 环境变量，不提供终端注册/SMTP/邀请码管理入口，也不提供后台修改管理员凭据的入口。

`.env` 权限为 0600。备份包含 `.env` 和数据库，因此同时保存部署参数和后台设置。保留现有管理员凭据，不要在首次创建后删除它们；以 `.env` 值为准。
