# 管理后台

这篇指南面向自己维护 Love 服务器的人。管理员可以创建和停用账号、配置注册和邮件、分配存储额度、查看日志。

## 登录后台

在浏览器打开 `你的访问地址/#admin`，使用部署向导设置的管理员账号登录。例如：

```text
https://love.example.com/#admin
```

普通用户页面没有后台入口，管理员账号也不用于两人日常聊天。

管理员密码忘了，或需要修改管理员账号时，在服务器上运行 `love`，进入“部署配置”重新设置并应用。它以部署配置为准，不在网页后台改密码。修改凭据后原后台登录会失效。

## 让双方获得账号

默认由管理员创建用户。到账号管理填写用户名、昵称、邮箱和初始密码，并确认邮箱属于该用户，再把账号交给对方。

如果希望用户自己注册，先配置好邮件服务，再在设置中选择注册方式：

| 注册方式     | 谁可以注册                           |
| ------------ | ------------------------------------ |
| 仅管理员创建 | 用户不能自行注册                     |
| 邮箱注册     | 符合邮箱域名规则的人，验证邮箱后注册 |
| 邮箱白名单   | 你加入白名单的邮箱，验证后注册       |

添加白名单不会直接创建账号。域名限制为空时不限制邮箱域名；设置后，白名单用户也需要符合域名限制。

注册规则只控制新账号。要阻止已有用户继续使用，应停用账号。停用、重设用户密码或撤销全部会话会让原登录失效；恢复账号后用户需要重新登录。

## 配置发送邮件

邮件用于注册验证和找回密码。在后台设置中填写 SMTP 主机、端口、加密方式、账号、密码或授权码、发件邮箱和显示名称。

通常 465 端口选择 TLS，587 端口选择 STARTTLS；以你的邮件服务商要求为准。某些服务需要“授权码”，不能直接使用邮箱登录密码。

先保存，再向自己的邮箱发一封测试邮件。提示已交给 SMTP 服务器，只表示服务接收了邮件；还要检查收件箱和垃圾邮件。修改其他设置时，密码留空会保留原密码；明确选择清除才会删除。

不要随意更换部署配置里的媒体密钥。邮件密码和 AI Key 也用它加密，更换后可能需要重新填写。完整备份会保存恢复所需的配置。

## 注册邀请码

需要限制注册人数时，开启“注册需要邀请码”，并在后台生成邀请码。邀请码可设置备注、可用次数、有效期，也可以停用。

完整邀请码只在生成时显示一次，及时下载 CSV 或保存。以后列表里可以查看用量和状态，但不能重新查看明文。管理员直接创建用户不需要邀请码。

注册邀请码决定能否注册；配对邀请码决定与谁建立两人空间。不要混用。

## 存储额度

每个两人空间有独立额度，新配对默认分配 1 GiB。后台可以调整默认额度，也可以单独调整某个空间。

修改默认额度只影响之后新建的配对，不会修改已有空间。额度设为 0 时禁止新增上传；降低额度不会删除原内容，已经超出上限的空间无法继续上传。个人头像不占两人空间额度，聊天和相册媒体、AI 头像占用该额度。

两人可以选择只保存压缩媒体，减少之后上传的占用，见 [使用指南](guide.md#原图原视频与容量)。

## 日志与维护

后台提供访问日志、服务事件和管理员操作记录，可以按时间、关键字或错误状态查找。日志不保存密码和聊天请求正文，但仍可能包含 IP 和账号标识，应按私人信息管理。

启动失败时可能还进不了网页后台。这种情况先用服务器上的管理菜单查看容器日志。备份、更新、恢复和清理媒体也在服务器管理菜单中操作，见 [日常维护](manage.md)。
