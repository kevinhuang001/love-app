# Android 使用

服务器部署好后，Android 应用和浏览器访问的是同一份聊天、相册和日程数据。

## 安装与连接

1. 从 [Releases](https://github.com/kevinhuang001/love-app/releases/latest) 下载 APK 并安装。
2. 打开应用，在登录页底部展开“服务器设置”。
3. 填完整访问地址，例如 `https://love.example.com` 或 `http://192.168.1.10:3000`。不加 `/api`。
4. 点击“测试连接”，成功后用自己的账号登录。

地址也可以包含 IPv6，例如 `http://[你的IPv6地址]:3000`。手机中的 `localhost` 是手机自身，不能用它访问电脑或服务器；`0.0.0.0` 是服务器监听设置，也不是可访问的地址。

## 更新应用

下载新版 APK 后直接覆盖安装，通常会保留登录信息。不要先卸载或清除数据。

覆盖安装要求新旧 APK 使用相同签名。如果 Android 提示签名不一致，联系 APK 提供者确认；不要为了更新反复生成新的签名密钥。卸载后再安装会丢失本机登录信息，但服务器中已经保存的内容仍在。

应用会记住服务器地址和用户名，不保存你输入的密码。登录过期、改密码或管理员撤销登录后，需要重新登录。

## 设置聊天通知

双方配对后，在 **我们 → 聊天通知** 中开启提醒：

1. 允许 Android 通知权限。
2. 打开后台运行设置，允许 Love 后台运行。
3. 如果系统有电池限制，将 Love 设为不受限制；部分手机还需要锁定最近任务中的应用。
4. 把 Love 切到后台，让另一方发送消息，确认能收到通知。

开启后通知栏会显示 Love 的连接状态，可用“停止接收”关闭。聊天通知正文不展示消息内容，点击通知进入聊天。

## 通知有什么限制

Love 由手机直接连接自己的服务器收消息，不使用厂商推送或第三方推送账号。手机断网、系统深度休眠，或系统把 Love 进程关闭，都可能导致延迟；进程关闭后不能靠远程推送把它唤醒。

重新打开应用后会恢复连接。退出登录、解除配对或关闭通知开关会停止接收。重启手机后需要重新打开应用，没有开机自启动。

## 返回键

返回键或返回手势会先收起键盘、关闭当前预览或弹窗，再从其他页面回到聊天。在主页面继续返回会退到后台，不会退出账号。

开发者构建 APK、配置固定签名和排查原生通知，请看 [Android 构建与签名](../developer/android.md)。

## 在应用内更新

在“我们 → 应用更新”点击“检查更新”，查看当前与最新正式 APK 版本。有新版本时点击“下载并安装更新”，显示下载进度并校验文件与签名。第一次安装需允许 Love 安装未知应用，返回后再次点击安装。更新必须使用与已安装版本相同的签名，覆盖安装保留登录信息。
