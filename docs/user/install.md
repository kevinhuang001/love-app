# 安装 Love

这篇指南适合准备在自己服务器上运行 Love 的人。安装完成后，你会得到一个访问地址、一个管理员账号，以及供双方使用的两个用户账号。

## 1. 准备服务器

需要 Linux 服务器，CPU 为 AMD64 或 ARM64，并已安装 Docker Engine 和 Docker Compose 2.24.4 或更新版本。可以用下面两条命令检查：

```sh
docker --version
docker compose version
```

需要让双方的设备能访问这台服务器。局域网使用可以直接填写服务器的局域网 IP；公网使用通常准备一个域名并配置 HTTPS。

## 2. 安装管理程序

在服务器终端进入一个专门的部署目录。首次安装可以这样做：

```sh
mkdir -p ~/love
cd ~/love
curl -fsSL https://raw.githubusercontent.com/kevinhuang001/love-app/main/install.sh | bash
```

安装器下载正式发布的 `love` 程序并打开菜单。以后在此目录运行 `./love`；普通账户需要管理数据卷时运行 `sudo ./love`。服务器已用 root 登录时不需要 sudo。

`love` 是服务器上的管理工具。手机 APK 和网页是使用 Love 的客户端，三者不是同一个文件。安装器不会帮你安装 Docker。

已有部署请在原来的 `love` 所在目录操作，避免另外创建一套配置和数据。

## 3. 选择“部署配置”

### 数据库怎么选

| 选项                      | 适合谁                                  | 数据放在哪里                   |
| ------------------------- | --------------------------------------- | ------------------------------ |
| SQLite                    | 想简单部署、没有独立数据库的人          | 服务器的应用数据卷             |
| PostgreSQL · Compose 内置 | 希望使用 PostgreSQL，但不想另行安装的人 | 自动创建的数据库容器和数据卷   |
| PostgreSQL · 外部数据库   | 已经有 PostgreSQL 服务的人              | 你填写的连接地址所指向的数据库 |

初次使用选 SQLite 即可。选择外部数据库时，需要事先创建可访问的数据库和有建表权限的数据库用户，再填写完整连接地址。可连接已有的、由当前迁移体系管理的 Love 数据库；不要连接其他应用的数据库。

首次配置 SQLite 或内置 PostgreSQL 时，保存配置后会询问是否导入备份。新建空白服务选择“否”；搬迁服务器选择“是”，再指定备份目录。外部数据库直接使用原有数据，不会在初始化时询问导入。恢复步骤见 [日常维护](manage.md#恢复备份)。

### 访问方式怎么选

| 你的情况                                 | 向导中的选择             | 访问地址示例               |
| ---------------------------------------- | ------------------------ | -------------------------- |
| 已有 Nginx、Caddy 等反向代理             | HTTPS → 已有反向代理     | `https://love.example.com` |
| 有域名，想由 Love 部署配套代理和证书服务 | HTTPS → Certbot 或 Caddy | `https://love.example.com` |
| 先在局域网体验                           | 不使用 HTTPS             | `http://192.168.1.10:3000` |

HTTPS 是访问网页和手机服务的加密连接。证书属于部署时可选的代理服务，Love 后端本身仍提供 HTTP。已有反向代理时，证书由你的代理管理；选择 HTTP 时不需要证书。

使用内置 HTTPS 前，把域名解析到服务器，并开放公网 TCP 80 和你选择的 HTTPS 端口。默认 HTTPS 端口是 443。Certbot 还会询问联系邮箱，并自动处理后续续期。

HTTP 监听地址中的 `127.0.0.1` 表示只允许服务器本机访问，适合代理与 Love 在同一台服务器上。`0.0.0.0` 表示监听全部 IPv4 网卡，局域网直接访问可选它。指定 IP 支持 IPv4 和 IPv6，但必须是服务器已有的地址。手机填实际 IP 或域名，不能填 `0.0.0.0`。

如果你的服务器通过云厂商 NAT 提供公网 IPv4，公网 IP 可能不会出现在服务器网卡上。这种情况通常监听 `0.0.0.0`，再在安全组放行端口。

### 设置管理员

设置管理员用户名和密码。用户名使用 3～24 位小写字母、数字或下划线，密码为 12～128 字符。密码留空时会自动生成，可在部署目录的 `.env` 文件中查看 `ADMIN_PASSWORD`。

管理员账号用于管理服务。双方日常聊天需要另外创建普通用户账号。

## 4. 启动并创建用户

保存配置后选择启动。管理程序下载应用镜像并等待服务就绪；通常不需要自己组合 Compose 命令。

用浏览器打开向导显示的访问地址，再在地址后加 `/#admin`，例如：

```text
https://love.example.com/#admin
```

登录管理后台，在账号管理中给双方各创建一个账号。默认不允许用户自行注册；需要邮箱注册时，按 [管理后台指南](admin.md) 配置。

双方回到普通登录页，用自己的账号登录，然后在“我们”里完成配对。接下来看 [使用指南](guide.md)；手机安装见 [Android 使用](android.md)。

## 没有启动成功

先在管理菜单选择“状态与版本”和“查看日志”。按日志中的具体错误检查，不要先删除数据卷。常见的端口、数据库和证书问题见 [常见问题](troubleshooting.md)。
